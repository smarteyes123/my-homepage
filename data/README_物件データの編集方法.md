# 物件データの編集方法

物件一覧は `data/properties.csv` を読んで表示しています。
HTML を触らずに、この CSV だけ編集すれば物件を増減できます。

---

## ⚠️ 保存するときの注意（これだけは必ず）

**必ず「UTF-8」で保存してください。**

Excel の「CSV（コンマ区切り）」で保存すると Shift-JIS になり、
サイト上で日本語がすべて文字化けします。

- Excel …… 「名前を付けて保存」→ ファイルの種類で **「CSV UTF-8（コンマ区切り）」** を選ぶ
- Numbers(Mac) …… 書き出す → CSV → テキストエンコーディング **UTF-8**
- Google スプレッドシート …… ダウンロード → CSV（最初から UTF-8 なのでそのままで可）

文字化けした場合、サイト側は表示せず、ブラウザの開発者コンソールに警告を出します。

## 列の説明

| 列 | 内容 | 書き方 |
|---|---|---|
| `public` | **公開するか** | `yes` で公開。それ以外(`no` など)は非公開で表示されません |
| `type` | 種別 | `sale`(売買) / `rent`(賃貸) / `investment`(投資) のいずれか |
| `area` | エリア | `shinjuku` / `shibuya` / `minato` / `chiyoda` のいずれか |
| `title` | 物件名 | 自由 |
| `location` | 所在地 | 自由（例: 新宿区西新宿） |
| `price` | 価格 | **数字だけ**。カンマや「円」は入れない（例: `85000000`）。表示時に自動でカンマが付きます |
| `price_unit` | 価格の単位 | 例: `円` / `円/月` |
| `rooms` | 間取り | 例: `3LDK` |
| `size` | 面積 | 例: `75㎡` |
| `floor` | 階数 | 例: `15/20階` |
| `features` | 特徴タグ | **縦棒 `|` で区切る**（例: `3LDK|築5年|南向き`） |
| `images` | 写真のファイル名 | `img/properties/` に置いた写真の**ファイル名だけ**を書く。複数は縦棒区切り（例: `bukken-1.jpg|bukken-2.jpg`）。空欄なら色地のサムネイルになります |

### 補足

- `price` に数字以外が入っていると価格での絞り込みが効かなくなります。
- `type` と `area` の綴りが違うと、検索で絞り込んだときに出てこなくなります。
- 行の途中にカンマを含めたい場合は、その項目全体を `"` で囲ってください。
  （例: `"新宿区西新宿7-3-10, 山京ビル"`）
- 空行は無視されます。1 行目の見出しは消さないでください。

## 写真の入れ方

1. 写真を **`img/properties/`** フォルダに直接入れる（物件ごとのサブフォルダは作りません）
2. CSV の `images` 列にそのファイル名を書く

```
images
bukken-nishishinjuku-1.jpg
```

複数ある場合は縦棒で区切ります（今はカードに 1 枚目だけ使います）。

```
bukken-nishishinjuku-1.jpg|bukken-nishishinjuku-2.jpg
```

### 写真の注意

- ファイル名は**半角英数字とハイフン**に。日本語名やスペースは避けてください
- **大文字小文字は区別されます**。`photo.JPG` と `photo.jpg` は別物として扱われます
- 幅 1200px 程度・1 枚 200KB 以下に縮小してから入れてください。
  Mac ならターミナルで:

  ```
  sips -Z 1200 元の写真.jpg --out img/properties/bukken-1.jpg
  ```

- ファイル名が違う・写真が無い場合は、**色地のサムネイルに自動で戻ります**。
  ページが崩れることはありません。

## 公開・非公開の切り替え

いま入っている 6 件は、以前 HTML の中に書かれていた**サンプルデータ**です。
実在の物件ではないため、`public` を全て `no` にしてあります。

- **1 件も `yes` が無いとき** …… 「おすすめ物件」の区画そのものが表示されません。
  （今のサイトと同じ見え方です）
- **`yes` があるとき** …… その物件だけが一覧に出ます。

実際の物件を載せるときは、サンプル行を書き換えるか削除して、
新しい行を足して `public` を `yes` にしてください。
